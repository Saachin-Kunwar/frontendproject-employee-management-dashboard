# 🚀 Employee Management Dashboard

A fully functional **Employee Management Dashboard** built using **HTML, CSS, and JavaScript**.  
This project demonstrates core frontend concepts like **CRUD operations, pagination, search, and localStorage-based data persistence**.

---

## 📌 Features

- ➕ Add new employees  
- ✏️ Edit and update employee details  
- ❌ Delete employees  
- 🔍 Real-time search (by name or department)  
- 📄 Pagination (Next / Previous navigation)  
- 💾 Data persistence using **localStorage**  
- ⚡ Dynamic table rendering  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling  
- **JavaScript (Vanilla JS)** – Logic & functionality  

---

## 🧠 Core Concepts Used

- DOM Manipulation  
- Event Handling  
- Array Methods (`filter`, `slice`, `splice`)  
- State Management (`currentPage`, `editIndex`)  
- Local Storage (JSON format)  
- Dynamic Rendering using `renderTable()`  

---

▶️ How to Run
Download or clone the repository
Open index.html in your browser
Start adding and managing employees

🎯 Learning Outcomes
Understanding how real-world CRUD applications work
Managing UI and data separately
Implementing efficient table rendering
Handling multiple features together (search + pagination + CRUD)
